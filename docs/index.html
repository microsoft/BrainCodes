At a Glance

BrainCodes is a compact foundation model for electroencephalography that operates entirely over discrete tokens produced by BioCodec, a frozen neural audio-style codec of high fidelity.

Each electrode is quantized independently into residual code streams, which a factorized transformer processes by alternating attention over time and over channels. Electrode identity enters only through rotary encodings of 3D coordinates, so a single set of weights serves any montage without retraining. Pre-training combines masked-code prediction with an auxiliary objective that localizes synthetic oscillatory bursts injected into the signal, and an hourglass bottleneck compresses the sequence before it is expanded again.

Discrete by design

EEG is tokenized once by a frozen RVQ tokenizer.

Montage-agnostic

Electrode ID enters through a function of 3D coordinates.

Small enough to matter

A 1.9M-parameter backbone that does on-device inference.

From electrodes to tokens to embeddings

Raw EEG

(B, C, T) at 250 Hz, band-pass filtered and montage-aligned on 3D coordinates.

Tokenizer

Per-channel RVQ codes (B, C, T ', K) from a frozen tokenizer of high fidelity.

Backbone

Factorized time and channel attention with coordinate-conditioned positions.

Embeddings

Token grid, channel-wise embeddings are fed to the downstream heads.

Three lines to an embedding

The released package ships pretrained weights and a minimal API. Full documentation lives in the associated GitHub repository.

install 
git clone https://github.com/microsoft/BrainCodes.git
cd BrainCodes && pip install -e .
# the frozen BioCodec tokenizer is a separate download
git clone https://github.com/klean2050/BioCodec-release.git
quickstart.py 
import torch
from braincodes import BrainCodesModel

ch_names = ["TP9", "AF7", "AF8", "TP10"]
model = BrainCodesModel.from_pretrained(ch_names, device="cuda")

eeg = torch.randn(8, 4, 1000)        # (B, C, T) @ 250 Hz
emb = model.embed(eeg, pool="channel")  # (B, C*D)

clf = model.build_classifier(num_classes=4, mode="linear_probe")
logits = clf(model.tokenize(eeg))

Intended use disclosure

BrainCodes is released for neuroscientific research. It is not intended to support clinical, diagnostic, or other high-impact decisions about individuals. The release contains model parameters only; we make no formal privacy guarantee, and the learned representations remain subject-discriminative.
